## The one thing worth remembering about this phase

LangGraph's fan-in join (`add_edge([...], target)`) requires ALL listed source nodes to fire in the same superstep. Routing a retry straight back to just the failing agent breaks this silently — the join never re-arms and the graph just stops advancing past Review with no error. The fix: a `retry_dispatch` node re-fans to all six writer agents on every retry, but each one internally skips real work unless it's the actual named target. Full explanation lives in `graph.py`'s module docstring and this phase's `PHASE.md` handoff notes.
